README 可以这样介绍

这是一个面向五类植物图像分类的实验复现与结果对比项目。已有训练代码支持单折快速验证和双架构五折流程；离线报告工具比较同一验证集上的指标、混淆矩阵与错误样本。

当前页面使用合成预测演示功能。尚无本次新训练成绩，不能据此声称某个模型更准确。
